# new1

A simple Python calculator application demonstrating basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division (with zero-division protection)

## Installation

No external dependencies are required. The application uses only Python's standard library.

```bash
# Clone the repository
git clone https://github.com/shuzixintu/new1.git
cd new1
```

## Usage

Run the calculator demo:

```bash
python main.py
```

## Running Tests

Run the unit tests:

```bash
python test_calculator.py
```

Or use Python's unittest module:

```bash
python -m unittest test_calculator.py
```

## Project Structure

- `calculator.py` - Core calculator module with Calculator class
- `main.py` - Main entry point demonstrating calculator usage
- `test_calculator.py` - Unit tests for the calculator
- `requirements.txt` - Project dependencies (none for this project)
